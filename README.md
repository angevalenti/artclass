# 🎨 Art Class — Holy Redeemer High School

Curriculum materials, syllabi, and SmartBoard resources for **3D Art** and **Visual Art I**.

---

## 📁 What's Inside

### 📄 `/syllabi`
Printable one-page syllabi for both courses — PDF and DOCX formats.

| File | Description |
|------|-------------|
| `3D_Art_Syllabus.pdf` | 🎨 3D Art — full year syllabus |
| `Visual_Art_I_Syllabus.pdf` | 🖌️ Visual Art I — semester syllabus |
| `*.docx` | Editable Word versions of each |

### 💻 `/smartboard`
Interactive React components designed for classroom SmartBoard display.

| File | Description |
|------|-------------|
| `curriculum-cheatsheet.jsx` | ✨ Year at a Glance — toggles between both courses with Big Ideas, Elements & Principles, Materials, and Projects |
| `first-day-doodle-icebreaker.jsx` | ✏️ The Big Doodle — first-day collaborative drawing activity with rotating prompts |

> **Note:** The `.jsx` files are React components built for [Claude Artifacts](https://claude.ai). Open them in a Claude conversation or deploy them in any React project.

---

## 🎯 Courses

### 🎨 3D Art (Full Year)
6 units covering hand-building, soft sculpture, architecture, relief, assemblage, and a student-choice capstone.

### 🖌️ Visual Art I (Semester)
6 units covering line & value, observation, color & painting, space & identity, mixed media, and portfolio showcase.

---

## 🎨 Design System
All materials share a unified visual identity:
- ⬜ White backgrounds with subtle accent colors
- 💚 Emerald (`#10B981`) for 3D Art
- 💗 Rose (`#E84393`) for Visual Art I
- 📝 Slate (`#2D3142`) for text
- 🔥 Emojis throughout
